Background

Why I Built It

Commercial wearables measure the autonomic nervous system through sleep, heart rate variability, and resting heart rate. Burnout in athletes is mainly psychological.

Research measures athlete burnout as exhaustion, a reduced sense of accomplishment, and losing interest in the sport. A wearable's recovery score can look normal while all three are getting worse.

Myaku keeps three kinds of data separate, scores each against the athlete's own history, and reports where they disagree.

How It Works

Three Channels

From A Wearable

Body

Sleep duration, sleep efficiency, heart rate variability, and resting heart rate, imported from Google Health (Fitbit), Apple Health, or Whoop.

From A Reaction Test

Brain

A three-minute psychomotor vigilance test that runs in the browser. A single session is too noisy to interpret, so results are pooled by week.

From The Athlete

Life

A short daily check-in, a weekly questionnaire with the three athlete burnout dimensions, and optional journal entries scored by a language model on the athlete's own computer.

  1. Seven-Day Readings

    Each channel is averaged over the last seven days, counted back from today.

  2. Your Own Normal

    Each week is compared with the athlete's earlier weeks using the median and median absolute deviation, so one bad night does not move the baseline.

  3. Two-Week Rule

    A channel has to stay outside its normal range for two consecutive weeks before it counts.

  4. Named Pattern

    The app names the combination of channels that are off, such as Head Under Strain.

Principles

Design Principles

Compare Only Against Yourself

Normal means the athlete's own recent weeks, not population ranges.

Patterns, Not Diagnoses

The app describes what the data shows and never diagnoses.

Private By Default

Journal entries are scored on the user's own computer with no cloud fallback, and wearable tokens are encrypted at rest.

No Streaks

Reminders skip anything already done that day.

Labeled Evidence

Each analysis is marked as a description, an exploratory search, or a pre-registered test.

Evidence

Validation

New users used to wait four weeks before the Body channel could be scored, because estimating a person's week-to-week variability takes at least three earlier weeks. Average levels differ a lot between people, but the size of their week-to-week variation is much more similar.

I measured that variation in LifeSnaps, a public dataset of Fitbit users followed for about four months, using the app's seven-day windows. Each user now starts with the population value, weighted as four weeks of their own data, and their own data takes over as it accumulates.

To test it, I replayed the scoring week by week for 37 to 59 participants, depending on the measure, leaving each person out of the population estimate applied to them. Body can now be scored from week 2 instead of week 4.

Calibration Finding

The old minimum spread, 4 percent of the athlete's average, was larger than the typical weekly variation in resting heart rate (about 2 percent) and sleep efficiency (under 1 percent), so real changes in both were hidden. The minimum is now set from population data.

Debugging

Problems I Found And Fixed

Google Health Parser

The API returns 64-bit integers as strings, so the first parser would have skipped every night of sleep.

Fix. Caught by checking the code against Google's published schema before I had a device, then covered by an end-to-end test against a mock server.

Stale Readings

A channel with no recent data could still set the week's pattern.

Fix. Patterns now use only channels with data from the last seven days.

Spread Floor

The fixed 4 percent minimum spread was larger than most people's real weekly variation in resting heart rate and sleep efficiency.

Fix. The floor for Body is now set from population data.

Database Exposure

A static-file setting served the database and the session secret.

Fix. Closed it, then added a content security policy, origin checks, rate limiting, and account deletion.

Citations

Checking every reference turned up three claims the cited papers did not support.

Fix. Corrected or removed each one, and added a test that fails if a page cites a source missing from the reference list.

Journal Page

Two elements shared an ID, which left the journal blank for signed-in users.

Fix. Found during a usability audit at phone width.
